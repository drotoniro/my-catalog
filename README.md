# Лабораторная работа 5: «Список товаров с фильтрами»

Одностраничное React-приложение (Vite) для отображения каталога товаров с загрузкой из `fakestoreapi.com` и фильтрацией по нескольким категориям и диапазону цен.

## Реализовано
- Загрузка данных через `fetch` с отменой запроса через `AbortController` при размонтировании.
- Состояния загрузки, ошибки и пустого результата.
- Мультивыбор категорий (массив в `useState`).
- Фильтр по минимальной и максимальной цене с числовыми полями, ползунками (`input type="range"`) и валидацией при нажатии «Применить фильтры».

## Запуск проекта

```bash
npm install
npm run dev
```
